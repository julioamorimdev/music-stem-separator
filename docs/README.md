# Music Stem Separator — Documentação

Bem-vindo! Este diretório contém toda a documentação do projeto **Music Stem Separator** para novos usuários.

## O que é Music Stem Separator?

**Music Stem Separator** é uma ferramenta de código aberto que permite separar as **vozes** (vocals) de uma música de seu **acompanhamento instrumental** com apenas alguns cliques.

Útil para:
- Criar versões sem vocais de suas músicas favoritas
- Extrair instrumentais para produção ou prática
- Experimentar com áudio sem ferramentas complexas

## Início rápido

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python web/app.py
```

Acesse: `http://127.0.0.1:5173`
